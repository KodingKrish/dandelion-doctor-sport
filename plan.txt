## 2. Unit-Binding (`FBSN: 6XLFMR9DVK7PCM6H`), Ethics & Safety Policy

1. **Strict Hardware Serial Lock (`FBSN` + `SOC_ID`):**
   - `adb` and `fastboot` transports reject any device whose serial is not `6XLFMR9DVK7PCM6H`.
   - On the first successful BROM handshake, `ME_ID` (16 bytes) and `SOC_ID` (32 bytes) are read from fused registers and hashed into `config/device_profile.yaml`. All future BROM operations verify that hardware identity automatically.
2. **Preloader Quarantine:**
   - `preloader` (eMMC `Boot1`) is **read-only by default** during all unbrick operations. Overwriting it with an incompatible EMI preloader turns a recoverable soft-brick into a dead-boot brick requiring testpoint recovery.
3. **Golden NV Vault Mandate:**
   - Zero destructive flash/erase commands are permitted until `proinfo`, `nvram`, `nvdata`, `nvcfg`, `protect1`, `protect2`, `persist`, `seccfg`, and `pgpt` are backed up and SHA-256 verified off-device.
4. **Legitimate Factory Repair Boundaries:**
   - IMEI/MAC/Serial recovery applies **solely** to restoring backups dumped from `6XLFMR9DVK7PCM6H` or restoring the **exact original factory identifiers printed on this unit's box/SIM tray/PCB** via META mode if wiped by an earlier `Format All`. Spoofing, cloning, or unauthorized lock/FRP/Mi-Account circumvention is explicitly excluded by code.

## 4. System Architecture & Technology Stack

### 4.1 Core Stack
- **Runtime:** Python `3.11+` (`pydantic` v2, `typer`, `rich`, `PySide6`, `sqlite3`, `pyusb`, `pyserial`).
- **Low-Level MediaTek Transport:** `bkerler/mtkclient` Python API + Kamakiri2 (`mt6765_payload.bin`) + EMI Preloader Injector.
- **Android Platform Tools:** Pinned `adb` & `fastboot` (with full `fastbootd` userspace logical partition support).
- **Image / Filesystem / AVB Tools:** `avbtool`, `simg2img`/`img2simg`, `lpunpack`/`lpmake`/`lpdump`, `e2fsck`/`debugfs`/`fsck.f2fs` (WSL2/Linux native or bundled binaries).
- **Fix Rule Engine (`RuleResolver`):** Indexes `assets/catalog/fixes_10560.jsonl` into an in-memory/SQLite FTS5 decision graph. Given live telemetry (`usb_vid_pid`, `dmesg_lines`, `logcat_lines`, `getvar_map`, `brom_error_code`, `partition_hashes`), it ranks exact matching `FIX-*` rules, filters by safety constraints, explains root cause, and executes automated or guided steps.

### 4.2 Execution Pipeline

```text
 [USB Hotplug & Telemetry Probe]
   (BROM / Preloader / DA / META / Fastboot / Fastbootd / ADB / Sideload)
                    |
                    v
 [Signature Extractor] ---> Matches against 10,560 Fixes in SQLite/JSONL
                    |
                    v
 [Safety Gatekeeper] ---> FBSN==6XLFMR9DVK7PCM6H | Vault Verified | Battery>=3.65V
                    |
                    v
 [Transaction Context] ---> Pre-Write Snapshot -> Execute Fix -> Readback Verify
                    |                     |
             (Success)              (Failure / Drop)
                    |                     |
                    v                     v
          [Post-Fix Audit]       [Auto-Rollback Rescue]
```

## 6. USB Transport Layer, Host Drivers & State Machine

### 6.1 Finite-State Machine (FSM) Modes

| State | USB VID:PID | Enumeration Name | Capabilities |
| :--- | :--- | :--- | :--- |
| `BROM` | `0E8D:0003` | `MTK USB Port` | Raw SRAM access via Kamakiri2; bypasses locked bootloader |
| `PRELOADER` | `0E8D:2000` | `MediaTek Preloader USB VCOM` | ~1.5s window at boot; crash-to-BROM or DA handshake |
| `DA_ACTIVE` | `0E8D:2001` | `MediaTek DA USB VCOM` | High-speed DRAM-initialized eMMC read/write |
| `META` | `0E8D:2007` | `MediaTek USB VCOM / CDC` | Baseband/NVRAM calibration & original IMEI/MAC restore |
| `FASTBOOT` | `18D1:D00D` / `2717:FF08` | `Android Bootloader Interface` | `getvar all`, unlock check, partition flash (if unlocked) |
| `FASTBOOTD` | `18D1:D00D` (`is-userspace:yes`) | Userspace Fastboot | Resize/flash logical partitions inside `super` (Android 11+) |
| `ADB_OS` | `2717:FF48` / `18D1:4EE7` | `Android ADB Interface` | Live telemetry, `dmesg`/`logcat`, `pm`, `fstrim`, `settings` |
| `ADB_RECOVERY` | `18D1:D001` / `2717:FF18` | TWRP/OFOX or Stock Mi Assistant | `adb sideload`, offline `fsck`, FBE data salvage |

### 6.2 Host OS Automation Rules
- **Linux (`udev` + `ModemManager` Guard):** Automatically installs `/etc/udev/rules.d/99-dandelion-mtk.rules` with `ATTRS{idVendor}=="0e8d", ENV{ID_MM_DEVICE_IGNORE}="1", MODE="0666"`. Verifies `ModemManager` does not hijack `0E8D:0003` during the 2-second BROM window.
- **Windows:** Checks registry/driver store for **UsbDk** (required for raw `libusb` BROM bulk I/O) and MediaTek VCOM serial drivers; flags driver signature enforcement or conflicting Qualcomm/Spreadtrum drivers.

## 7. Phase 0: Forensic Backup & Encrypted Golden Vault

Before **any** partition write or format occurs:

1. Enter `BROM` -> `DA_ACTIVE` (or rooted `ADB_RECOVERY`).
2. Read `PGPT` (`0x0`–`0x8000`) and validate total eMMC geometry (~`32 GB`).
3. Dump all **Tier 1 (Identity/NV/Persist)** and **Tier 2 (Bootchain)** partitions:
   - `proinfo`, `nvram`, `nvdata`, `nvcfg`, `protect1`, `protect2`, `persist`, `seccfg`, `preloader`, `pgpt`, `sgpt`, `lk`, `lk2`, `tee1`, `tee2`, `scp1`, `scp2`, `sspm_1`, `sspm_2`, `spmfw`, `mcupmfw`, `md1img`, `dtbo`, `vbmeta*`, `boot`, `recovery`.
4. **Entropy & Sanity Check:** Automatically calculates Shannon entropy and non-zero byte ratio on `nvram`, `nvdata`, and `persist`. If any NV partition is all-`0x00` or all-`0xFF`, flags `NV_PRE_WIPED` immediately so a clean template/META restoration workflow is queued instead of overwriting with blank backups.
5. Writes AES-256-GCM encrypted vault + plaintext SHA-256 manifest in `backups/6XLFMR9DVK7PCM6H/manifests/`.

## 9. Deep Subsystem Repair Engines (All 15 Domains)

### 9.1 USB, VCOM & Host Transport Engine (Domain 01 — 360 Fixes)
- Resolves descriptor enumeration failures, `COM` port collisions, `ModemManager` race conditions, WinUSB/UsbDk filter misbindings, USB 3.0 xHCI root-hub power drops (auto-advises USB 2.0 hub/port), and intermittent Micro-USB data-pin dropouts.

### 9.2 BROM, Preloader, SLA/DAA & SP Flash Tool Error Resolution (Domain 02 — 840 Fixes)
Maps **42 specific MTK/SP Flash Tool error codes** across all 4 RAM/board revisions (`2GB/3GB Micron/Samsung-Hynix`) and 5 boot states:

| Code | Hex / Symbol | Meaning on `MT6765` (`dandelion`) | Automated Fix Action |
| :--- | :--- | :--- | :--- |
